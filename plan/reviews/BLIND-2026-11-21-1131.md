## 🟠 MAJOR (should be fixed)

### 1. A case that fails in process 2 or later is still ranked, with no SKIPPED and exit 0

`lab/micro/micro.php:326-345` · **Certainty:** verified (code path), the trigger is plausible

- **Why:** `micro_summarize()` only looks at `$processes[0]['status']`. When process 1 is `ok` and a later process ends
  in `check_failed` or `error`, the orchestrator marks the case dead (`:251-253`, the later processes are not run),
  `array_column($processes, 'median_ns')` silently drops the failed process, and the summary comes out `status: ok`
  with the median of the processes that passed. With one process left, `unstable` is false (`count($medians) > 1`).
  The row prints a normal number, `$skipped` stays 0 (`:271-274`), and `micro.sh` exits 0. In the JSON,
  `array_diff_key` also strips `status` from each process (`:344`), so the failed one only shows as a bare `message`.
- **Scenario:** a write bench for the POST step: `setup` opens `micro_feed_copy()`, `run` inserts a post, `check`
  wants `lastInsertId() === 1000001`. Process 1 starts from the fresh copy and passes. The copy is made once per
  container (`micro_feed_copy()`, `:76-86`) and process 1's timing loop inserted thousands of rows, so process 2's
  check fails. The table shows `insert/prepared 9.8 9.8 .. 9.8` as a valid, stable result from 1 process, next to
  variants measured on 5. Same thing with any check that depends on state or time (a token that expires, a random
  input).
- **Flips if:** every check is meant to be deterministic and every bench that writes recopies the database itself
  (the README asks for it at `lab/README.md:96-97`, but nothing enforces it).
- **Fix:** in `micro_summarize()`, return the first process that is not `ok` (`status` and `message`) instead of
  looking at `$processes[0]` only, so the row says `SKIPPED` and counts in `$skipped`. Keep `status` in the per-process
  entries of the JSON. Test: a fixture in `lab/micro/benches/` whose check passes on the first call of a process
  family and fails after (a counter in a file under `sys_get_temp_dir()`), and a `check.sh` case that expects
  `SKIPPED` for it.
